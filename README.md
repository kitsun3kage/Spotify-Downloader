# Spotify Downloader

A modern React + TypeScript frontend for Spotify metadata, playlist management and legal local downloads.

The project is designed specifically for GitHub Pages.

## Important

This project does not:

- bypass Spotify DRM
- rip Spotify streams
- download Spotify audio
- intercept Spotify streams
- expose a Spotify client secret
- use a backend
- use Vercel
- use Netlify
- use Firebase
- use Supabase
- use serverless functions

Spotify content is used for metadata, search, playlist information and preview playback where Spotify provides a preview URL.

The download manager is intended for legal direct files that the user has permission to download.
